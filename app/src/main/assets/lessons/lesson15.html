Lists and Dictionaries

Collections let one variable hold multiple related values. Python lists are ordered; dictionaries associate keys with values.

Lists

colors = ["blue", "green", "purple"]
print(colors[0])       # blue
print(colors[-1])      # purple

colors.append("gold")
colors[1] = "teal"
print(len(colors))

List indexes start at zero. Negative indexes count backward from the end. Common operations include append(), pop(), and len().

for color in colors:
    print(color)

Dictionaries

student = {
    "name": "Kai",
    "grade": 10
}

print(student["name"])
student["grade"] = 11
student["active"] = True

A dictionary stores key-value pairs. Use a key to read or update a value. The in operator can check whether a key exists.

if "grade" in student:
    print(student["grade"])

Choosing a collection

  • Use a list for an ordered sequence of items.
  • Use a dictionary when each value should be looked up by a meaningful key.

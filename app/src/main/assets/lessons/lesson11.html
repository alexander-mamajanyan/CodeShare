Python Basics

Python programs are made from readable statements. Start with values, variables, and a few built-in functions.

Your first statements

print("Hello, world!")
print(2 + 3)

print() displays a value. Text goes inside quotes; numbers can be used directly in calculations.

Variables and types

A variable is a name that refers to a value. Python figures out the value's type when the program runs.

name = "Mina"        # str: text
age = 16             # int: whole number
temperature = 21.5   # float: decimal number
is_learning = True   # bool: True or False

print(name, age)

Use clear names such as total_price. Names are case-sensitive, cannot start with a number, and should not contain spaces.

Getting input

name = input("What is your name? ")
print("Welcome,", name)

input() always returns text. Convert it before doing numeric calculations:

age_text = input("Age: ")
age = int(age_text)
print(age + 1)
Remember: use int() for whole numbers and float() for decimal numbers.

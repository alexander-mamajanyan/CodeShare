Loops and Iteration

Loops repeat a block of code. Use a for loop when working through a sequence, and a while loop when repetition depends on a condition.

for loops and range()

for number in range(1, 6):
    print(number)

range(1, 6) produces 1 through 5: the starting value is included and the ending value is not. You can also loop through text or a list.

for letter in "cat":
    print(letter)

while loops

count = 3
while count > 0:
    print(count)
    count -= 1
print("Go!")

Make sure something inside a while loop can eventually make its condition false. Otherwise the loop may never stop.

Accumulating a result

total = 0
for number in range(1, 5):
    total += number
print(total)  # 10

break exits a loop early. continue skips the rest of the current iteration and moves to the next one.

Conditions and Boolean Logic

Conditions let a program choose which statements to run. A condition evaluates to either True or False.

Comparisons

score = 82
print(score >= 60)  # True

Python comparison operators are ==, !=, <, <=, >, and >=. Use == to compare values; a single = assigns a value.

if, elif, and else

Indentation marks the statements in each branch. Keep the indentation consistent.

score = 82

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "Keep practicing"

print(grade)

Python checks branches from top to bottom and runs the first matching branch. else is optional and catches everything not matched above.

Combining conditions

age = 19
has_ticket = True

if age >= 18 and has_ticket:
    print("Welcome")

if age < 13 or age >= 65:
    print("Discount")

if not has_ticket:
    print("Please buy a ticket")

and requires both sides to be true, or requires at least one, and not reverses a boolean value.

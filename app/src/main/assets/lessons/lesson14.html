Functions

A function is a named, reusable block of code. Functions help break a problem into smaller pieces and avoid repeating logic.

Define and call a function

def greet(name):
    print("Hello,", name)

greet("Ari")

def starts a definition. The indented body runs only when the function is called. Here, name is a parameter and "Ari" is the argument.

Return a result

def rectangle_area(width, height):
    return width * height

area = rectangle_area(4, 3)
print(area)  # 12

return sends a value back to the caller and ends the function. If a function has no return statement, it returns None.

Defaults and scope

def greet(name, greeting="Hi"):
    message = greeting + ", " + name
    return message

print(greet("Sam"))
print(greet("Sam", "Welcome"))

A parameter can have a default value. Variables created inside a function are local to it; pass in values the function needs instead of relying on unrelated global variables.
